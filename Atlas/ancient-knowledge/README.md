## Tiering rules (her standing rules, restated)

- Documented fact / interpretation / hypothesis / speculation-fiction
  stay distinct; falsifiability required; negative/null results
  preserved; fiction is analogy/blind-spot checking only, never
  evidence.
- Pasted third-party AI material stays labeled as a paste until
  verified against a primary source.
- Her selective stance: "not everything, but certain things" — the
  correct explanation for each thing, because otherwise "our society
  is founded on plenty of false truths."
- Her reset position (mechanism, not mythology): institutions using
  their CURRENT resources to push a population into a certain way of
  acting. Orphan trains were real but did not fill empty cities.
